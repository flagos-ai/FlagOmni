# Security

## Report a vulnerability

Please do not disclose security vulnerabilities in public issues or pull
requests. Follow the
[FlagOS security reporting guidance](https://github.com/flagos-ai/community/blob/main/contributors/CONTRIBUTING.md#reporting-security-issues)
and email [contact@flagos.io](mailto:contact@flagos.io).

Include the affected repository (`flagos-ai/FlagOmni`), revision or version,
impact, relevant environment details, and reproduction steps when available.
Remove credentials, personal information, and unrelated private data from any
logs or examples.

Coordinate public disclosure with the maintainers so they can prepare a fix
before broad exposure.
